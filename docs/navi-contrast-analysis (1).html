Key Findings

  • On dark teal (#2D5F5A): Use white or very light colours (pale teals, creams, yellows all work)
  • On medium teal (#4DB6AC): Both very dark colours AND white can work, giving you flexibility
  • On light teal (#80CBC4): Stick to dark colours (deep teals, greys, near-black)
  • You can maintain brand consistency by using teal variations (#004D40, #00695C) as text colours on lighter backgrounds
  • Warm accents (cream, light yellow) can add visual interest whilst maintaining accessibility

Recommended Strategy for NaVi

  • Primary text: Pure white (#FFFFFF) on all dark teal backgrounds for maximum readability
  • Secondary text: Mint cream (#E0F2F1) for subtle hierarchy whilst maintaining AA compliance
  • Interactive elements: Consider warm cream (#FFECB3) for hover states or accent text
  • Alternative: Use deep teal (#004D40) text on light teal backgrounds for inverted sections
  • Test final colour combinations with tools like WebAIM's Contrast Checker or Colour Oracle

WCAG 2.1 Standards Reference

  • Level AA (minimum): 4.5:1 for normal text, 3:1 for large text (18pt+ or 14pt+ bold)
  • Level AAA (enhanced): 7:1 for normal text, 4.5:1 for large text
  • These standards ensure readability for users with visual impairments, colour blindness, and low vision
  • Meeting AA is legally required for many organisations; AAA is best practice
